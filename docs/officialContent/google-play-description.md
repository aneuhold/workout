## Notes on copy choices

- **Hook** (`Stop guessing. Start growing.`) — short, punchy, frames the core pain point.
- **Keywords seeded naturally**: hypertrophy, mesocycle, muscle, training, workout, bodybuilding, progressive overload, volume, fatigue, periodization, hypertrophy training app. These match the tags you'll select and help Google Play's search surface the app.
- **Section headers in caps** — Google Play doesn't render markdown, so caps + line breaks are the standard way to create visual structure.
- **Bulleted features** use `•` (rendered) rather than `-` (sometimes shown as literal dashes on Play).
- **Two-audience pitch** (beginners + experienced) widens the funnel without diluting the message.
- **Call to action** at the end nudges the download button.
